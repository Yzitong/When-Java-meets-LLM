# 排序

**1、稳定性**

排序算法的**稳定性**可定义为：若待排序序列中存在**值相等的元素**，且这些相等元素在**原序列中的相对先后顺序**，在排序完成后能**保持不变**，则称该排序算法是**稳定的**；反之，若相等元素的相对顺序可能被改变，则算法是**不稳定的**。

- 归并排序、冒泡排序、插入排序、计数排序是稳定的。
- 选择排序、快速排序、希尔排序、堆排序是不稳定的。

**2、时间复杂度**

最基础的四个算法：冒泡、选择、插入、快排中，**快排的时间复杂度最小\($O(n*log_2n)$\)，其他都是\($O(n^2)$\)**。

| 排序法 | 平均时间     | 最差情形               | 稳定度 | 额外空间     | 备注                              |
| ------ | ------------ | ---------------------- | ------ | ------------ | --------------------------------- |
| 冒泡   | \(O(n^2)\)   | \(O(n^2)\)             | 稳定   | \(O(1)\)     | n 小时较好                        |
| 选择   | \(O(n^2)\)   | \(O(n^2)\)             | 不稳定 | \(O(1)\)     | n 小时较好                        |
| 插入   | \(O(n^2)\)   | \(O(n^2)\)             | 稳定   | \(O(1)\)     | 大部分已排序时较好                |
| 基数   | \(O(logRB)\) | \(O(logRB)\)           | 稳定   | \(O(n)\)     | B 是真数 (0-9)，R 是基数 (个十百) |
| Shell  | \(O(nlogn)\) | \(O(ns)\)（\(1<s<2\)） | 不稳定 | \(O(1)\)     | s 是所选分组                      |
| 快速   | \(O(nlogn)\) | \(O(n^2)\)             | 不稳定 | \(O(nlogn)\) | n 大时较好                        |
| 归并   | \(O(nlogn)\) | \(O(nlogn)\)           | 稳定   | \(O(1)\)     | n 大时较好                        |
| 堆     | \(O(nlogn)\) | \(O(nlogn)\)           | 不稳定 | \(O(1)\)     | n 大时较好                        |

### **3.归并排序（重点）**

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250826210554102.png" alt="image-20250826210554102" style="zoom: 50%;" />

```java
static void merge_sort_recursive(int[] arr, int[] result, int start, int end) {
 
 // 1、分解到最小需要解决的地步，无法再分解了
    if (start >= end){
        // 需要开始解决问题
        return;
    }
    
    // 2、解决
        
    // 计算数组 arr 的中间位置    
    int mid = (start + end ) / 2;
    
    // start1 为左区间的开始位置
    int start1 = start;
        
    // end1 为左区间的结束位置
    int end1 = mid;
    
    // start2 为右区间的开始位置
    int start2 = mid + 1;
    
    // end2 为右区间的结束位置
    int end2 = end;
    
    // 调用 merge_sort_recursive 函数，将 arr 数组中的 start1 到 end1 这一区间的数字排序后，并存放到 result 中
    merge_sort_recursive(arr, result, start1, end1);
    
    // 调用 merge_sort_recursive 函数，将 arr 数组中的 start2 到 end2 这一区间的数字排序后，并存放到 result 中
    merge_sort_recursive(arr, result, start2, end2);
    
    // 3、合并
    
    // 将左右区间中较小的数字存放到 result 中，从 k 开始
    int k = start;
    
    while (start1 <= end1 && start2 <= end2){
        // 如果 arr[start1] < arr[start2])
        if(arr[start1] < arr[start2]){
            // result[k] 存放的是 arr[start1]
            result[k] = arr[start1] ;
            start1++;
            k++;
        }else{
            // 否则，result[k] 存放的是 arr[start2]
            result[k] = arr[start2] ;
            start2++;
            k++;
        }
        
    }
    
    // 如果左区间中还有元素，那么把它都添加到 result 中
    while (start1 <= end1){
        result[k] = arr[start1];
        k++;
        start1++;
    }
    
    // 如果右区间中还有元素，那么把它都添加到 result 中
    while (start2 <= end2){
        result[k] = arr[start2];
        k++;
        start2++;
    }
    
    // 最后，把结果赋值到 arr 中
    for (k = start; k <= end; k++)
        arr[k] = result[k];
}
public static void merge_sort(int[] arr) {
    int len = arr.length;
    int[] result = new int[len];
    merge_sort_recursive(arr, result, 0, len - 1);
}
```

### **2.快速排序（重点）**

**平均情况下，时间复杂度为O（nlogn）**

本质是**分治思想 + 原地分区**

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250826210159444.png" alt="image-20250826210159444" style="zoom:33%;" />

```java
import java.util.Random;
class Solution {
    private static final Random rand = new Random(); // 随机数生成器，避免频繁创建
    public int[] sortArray(int[] nums) {
        int n = nums.length;
        quiksort(nums,0,n - 1);
        return nums;
    }
    //快排的主方法
    private void quiksort(int[] nums,int left,int right){
        if (left >= right) return;
        int mid = partition(nums,left,right);
        quiksort(nums,left,mid - 1);
        quiksort(nums,mid + 1,right); 
    }
    //分治的函数,pivot 前面的元素小于等于它，pivot 后面的元素大于等于它
    //然后返回相遇的索引值，作为之后的下一个分治点
    private int partition(int[] nums,int left,int right){
        // 1. 随机选择pivot：在[left, right]范围内随机选一个索引
        int randomIndex = left + rand.nextInt(right - left + 1);
        //将随机索引位置的数交换到左侧
        int temp = nums[left];
        nums[left] = nums[randomIndex];
        nums[randomIndex] = temp;

        int pivot = nums[left];
        while (left < right){
            while (left < right && nums[right] >= pivot){
                right--;
            }
            nums[left] = nums[right];
            while(left < right && nums[left] < pivot){
                left++;
            }
            nums[right] = nums[left];
        }
        nums[left] = pivot;//相遇点设为pivot
        return left;
    }
    
}
```

### 3.**堆排序（重点）**

**堆是一种完全二叉树，分为大根堆和小根堆，升序利用大根堆，降序利用小根堆**

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250826210311988.png" alt="image-20250826210311988" style="zoom: 25%;" />

**一些规律（数学可推，背）**

**1.第一个叶子结点的索引len/2，所以最后一个非叶子结点的索引是len/2 - 1**

**2.当父结点的索引是i时，其左结点索引为2\*i + 1，右结点索引为2\*i + 2**

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250826210432281.png" alt="image-20250826210432281" style="zoom:33%;" />

```java
class Solution {
    // 堆排序的主函数
    public static void heapSort(int[] arr) {
        int n = arr.length;
        // 构建最大堆
        for (int i = n / 2 - 1; i >= 0; i--) {//从第一个非叶子结点开始调整，因为叶子节点是不用调整的
            heapify(arr, n, i);
        }
        // 逐个提取堆顶元素并调整堆为最大堆
        for (int i = n - 1; i > 0; i--) {
            // 将堆顶元素（最大值）与当前堆的最后一个元素交换
            int temp = arr[0];
            arr[0] = arr[i];
            arr[i] = temp;
            // 调整剩余元素，使其重新成为最大堆
            heapify(arr, i, 0);
        }
    }
    // 调整堆的函数,以 i 为根节点的子树，调整为最大堆
    private void heapify(int[] arr, int n, int i) {
        int largest = i; // 初始化最大值为当前节点
        int left = 2 * i + 1; // 左子节点
        int right = 2 * i + 2; // 右子节点
        // 如果左子节点大于当前最大值，则更新最大值
        if (left < n && arr[left] > arr[largest]) {
            largest = left;
        }
        // 如果右子节点大于当前最大值，则更新最大值
        if (right < n && arr[right] > arr[largest]) {
            largest = right;
        }
        // 如果最大值不是当前节点，则交换并继续调整堆
        if (largest != i) {
            int swap = arr[i];
            arr[i] = arr[largest];
            arr[largest] = swap;
            // 递归调整被影响的子树（以largest为根节点的子树）确保子树也满足最大堆
            heapify(arr, n, largest);
        }
    }
}
```
