# 双指针

## 移动零

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        //思路：双指针，最后的效果是前面都是非零数，后面都是0，所以把非零数都换到前面
        //left位置存储的是下一个非零数的位置，右指针从头到尾遍历，需要非零数就与left位置交换。
        int n = nums.length, left = 0, right = 0;
        while (right < n) {
            if (nums[right] != 0) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                left++;
            }
            right++;
        }
    }
}
```

## 盛最多水的容器

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

```java
class Solution {
    public int maxArea(int[] height) {
        //思路：双指针，直到相遇为止。
        int max = 0;
        int left = 0;
        int right = height.length - 1;
        while(left < right){
            //容器的高由短板决定
            int h = Math.min(height[right],height[left]);
            //哪边短哪边移动
            if(height[right] < height[left]){
                max = Math.max(max,h * (right -left));
                right--;
            }
            else{
                max = Math.max(max,h * (right -left));
                left++;
            }
        }
        return max;
    }
}
```

## 三数之和

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        //思路：先排序，后双指针，一个外部数组的迭代，然后内部双指针。
        //难点在于有很多判断来确保三元组不能重复
        List<List<Integer>> res = new ArrayList<>();
        //排序，先排序的目的一是为了缩减和的范围，二是为了方便确保三元组不重复
        Arrays.sort(nums);
        int len = nums.length;
        //外部数组迭代
        for (int i = 0;i < len;i++){
            //内部双指针
            int right = len -1;
            int left = i+1;
            while(left < right){
                int sum = nums[i] + nums[right] + nums[left];
                if (sum == 0){
                    //细节！Arrays.asList，把数组转换为list
                    res.add(Arrays.asList(nums[i], nums[right], nums[left]));
                    //细节！因为不允许重复，所以要向后移动
                    while (left < right && nums[left] == nums[left + 1]){
                        left++;
                    }
                    while (left < right && nums[right] == nums[right - 1]){
                        right--;
                    }
                    left++;
                    right--;
                }else if(sum < 0){
                    left++;
                }else{
                    right--;
                }
            }
            //细节！因为不允许重复
            while(i < len -1 && nums[i] == nums[i + 1]){
                i++;
            }
        }

        return res;
    }
}
```

## 接雨水

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

![image-20250826105347102](https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250826105347102.png)

```java
class Solution {
    public int trap(int[] height) {
        //思路：某柱子上方能接住的雨水量=该柱子左右两侧最高柱子高度的较小值-该柱子自身的高度。
        //利用双指针去迭代，记录两侧的最高柱子，进一步再得到最小值
        int res = 0;
        int len = height.length;
        int right = len - 1;
        int left = 0;
        int leftMax = 0,rightMax = 0;
        while (left < right){
            leftMax = Math.max(height[left],leftMax);
            rightMax = Math.max(height[right],rightMax);
            
            //说明left位置的右侧一定存在比leftMax更高的柱子
            if (leftMax < rightMax){
                //因此left位置的左右最大高度的较小值是leftMax，该位置能接的雨水为leftMax - height[left]
                res += leftMax - height[left];
                left++;//谁小移动谁，才有移动的意义
            }else{//说明right位置的左侧一定存在比rightMax更高的柱子
                res += rightMax - height[right];
                right--;
            }
        }
        return res;
    }
}
```
