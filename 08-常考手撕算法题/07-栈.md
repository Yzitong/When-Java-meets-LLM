## 字符串解码

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `105`。

**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**提示：**

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]` 

```java
class Solution {
    public String decodeString(String s) {
        // 辅助栈，用于存储倍数和中间结果
        Stack<Object> stack = new Stack<>();
        // 用于构建结果的字符串
        StringBuilder res = new StringBuilder();
        // 用于计算倍数的变量
        int multi = 0;
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 处理多位数情况，例如"123"需要解析为123
                multi = multi * 10 + (c - '0');
            } else if (c == '[') {
                // 遇到左括号，将当前倍数和结果入栈，并重置
                stack.push(multi);
                stack.push(res.toString());
                multi = 0;          // 重置倍数
                res = new StringBuilder();  // 重置当前结果，准备处理括号内内容
            } else if (c == ']') {
                // 遇到右括号，出栈并拼接字符串
                String lastRes = (String) stack.pop();  // 上一个[前的字符串
                int curMulti = (int) stack.pop();        // 当前[对应的倍数
                
                // 拼接：上一个结果 + 当前结果重复curMulti次
                StringBuilder temp = new StringBuilder(lastRes);
                for (int i = 0; i < curMulti; i++) {
                    temp.append(res);
                }
                res = temp;  // 更新当前结果为拼接后的结果
            } else {
                // 普通字符直接添加到当前结果
                res.append(c);
            }
        }
        
        return res.toString();
    }
}
```
