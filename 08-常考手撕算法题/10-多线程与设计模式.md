# 多线程与设计模式

## 交替打印 FooBar（lc 1115）

给你一个类：

```
class FooBar {
  public void foo() {
    for (int i = 0; i < n; i++) {
      print("foo");
    }
  }

  public void bar() {
    for (int i = 0; i < n; i++) {
      print("bar");
    }
  }
}
```

两个不同的线程将会共用一个 `FooBar` 实例：

- 线程 A 将会调用 `foo()` 方法，而
- 线程 B 将会调用 `bar()` 方法

请设计修改程序，以确保 `"foobar"` 被输出 `n` 次。

```java
class FooBar {
    private final int n;
    private boolean flag = true;//用于线程之间交替

    public FooBar(int n) {
        this.n = n;
    }

    public void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            synchronized (this) {
                while (!flag) {
                    this.wait();//flag = false时等待
                }
                printFoo.run();
                flag = false;
                this.notify();
            }
        }
    }

    public void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            synchronized (this) {
                while (flag) {
                    this.wait();//flag = true时等待
                }
                printBar.run();
                flag = true;
                this.notify();
            }
        }
    }
}
```

## 交替输出1A2B3C4D5E6F7G

要求创建两个线程，分别打印字符数组 `{"1","2","3","4","5","6","7"}` 和 `{"A","B","C","D","E","F","G"}`，**保证两个线程交替执行**，最终输出结果为 `1A2B3C4D5E6F7G`。

```java
public class sync_wait_notify {
    public static void main(String[] args) {
        final Object lock = new Object(); // 锁对象，用于线程同步

        char[] numChars = "1234567".toCharArray(); // 数字字符数组
        char[] letterChars = "ABCDEFG".toCharArray(); // 字母字符数组

        // 线程1：打印数字
        new Thread(() -> {
            synchronized (lock) {
                for (char c : numChars) {
                    System.out.print(c);
                    try {
                        lock.notify(); // 通知等待的线程（唤醒打印字母的线程）
                        lock.wait();   // 释放锁并进入等待状态
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }
                lock.notify(); // 最后一次循环后，主动通知，避免另一个线程永久等待
            }
        }).start();

        // 线程2：打印字母
        new Thread(() -> {
            synchronized (lock) {
                for (char c : letterChars) {
                    System.out.print(c);
                    try {
                        lock.notify(); // 通知等待的线程（唤醒打印数字的线程）
                        lock.wait();   // 释放锁并进入等待状态
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }
                lock.notify(); // 最后一次循环后，主动通知（理论上可省略，因为已执行完）
            }
        }).start();
    }
}
```
