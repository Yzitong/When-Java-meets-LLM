# 动态规划

**动态规划的核心要素回顾**

动态规划解决问题的核心思路是：

1. **分解问题**：将复杂问题拆解为规模更小的子问题；
2. **存储子问题解**：用某种数据结构记录子问题的解（避免重复计算）；
3. **状态转移**：通过子问题的解推导出更大问题的解（建立递推关系）。

## 爬楼梯

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

```java
class Solution {
    public int climbStairs(int n) {
        //典型的动态规划，即找出数列的通式与初值
        //爬第n阶楼梯的方法数量，等于 2 部分之和
        //1. 爬上n−1阶楼梯的方法数量。因为再爬1阶就能到第n阶
        //2. 爬上n−2阶楼梯的方法数量，因为再爬2阶就能到第n阶
        //为了让索引位置不越界
        int dp[] = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2;i<=n; i++){
            dp[i] = dp[i -1] + dp[i - 2];
        }
        return dp[n];

    }
}
```

## 杨辉三角

给定一个非负整数 *`numRows`，*生成「杨辉三角」的前 *`numRows`* 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        // 用于存储最终结果的列表
        List<List<Integer>> triangle = new ArrayList<>();

        // 初始化第一行，第一行只有一个元素 1
        List<Integer> firstRow = new ArrayList<>();
        firstRow.add(1);
        triangle.add(firstRow);

        // 从第二行开始构建杨辉三角
        for (int i = 1; i < numRows; i++) {
            // 获取上一行
            List<Integer> prevRow = triangle.get(i - 1);
            // 当前行的列表
            List<Integer> currentRow = new ArrayList<>();

            // 每行的第一个元素为 1
            currentRow.add(1);

            // 计算当前行中间的元素，每个元素等于上一行相邻两个元素之和
            for (int j = 1; j < i; j++) {
                currentRow.add(prevRow.get(j - 1) + prevRow.get(j));//语法，在List获取目标索引位置的值
            }

            // 每行的最后一个元素为 1
            currentRow.add(1);

            // 将当前行添加到结果列表中
            triangle.add(currentRow);
        }

        return triangle;
    }
}
```

## 打家劫舍

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

```java
class Solution {
    public int rob(int[] nums) {
        //典型的动态规划题，分类讨论，前n间房子能偷窃到的最高金额是dp[n]
        //对于第 i+1 间房子（即 nums[i]），有两种选择 —— 偷或不偷，取两种选择的最大值
        //可以得到dp[n+1]=max(dp[n],dp[n−1]+num)
        int n = nums.length;
        int dp[] = new int[n + 1];
        dp[0] = 0;
        dp[1] = nums[0];
        for(int i = 1;i < n; i++){
            dp[i + 1] = Math.max(dp[i],dp[i - 1]+ nums[i]);
        }
        return dp[n];
    }
}
```

## 完全平方数

给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

```java
class Solution {
    public int numSquares(int n) {
        //动态规划：将所有情况递推出来，将结果存储起来
        //一般dp[n]都是代表数字n满足题意的答案，这里dp[i] 表示和为 i 的完全平方数的最少数量。
        //因为它肯定是减去比它小平方数个数，dp[i] = MIN(dp[i], dp[i - j * j] + 1)，i表示当前数字，j*j表示平方数
        int dp[] = new int[n+1];
        Arrays.fill(dp, Integer.MAX_VALUE);//初始时用 Integer.MAX_VALUE（最大值）填充 dp 数组
        dp[0] = 0;
        for (int j = 1; j * j <= n; j++) {//j：列举出的可能组合成功的平方数下的整数
            for (int i = j * j; i <= n; i++) {//i:递推目标结果
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
                //dp[i - j * j] 表示和为 i - j * j 的最少完全平方数数量，加上当前的完全平方数 j * j 就可以得到和为 i 的一种组合
            }
        }
        return dp[n];
    }
}
```

## 零钱兑换

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        //将硬币从小到大排序
        Arrays.sort(coins);
        //建立存储结果的dp数组
        int dp[] = new int[amount + 1];//因为还要存储一个0，所以需要amount + 1
        Arrays.fill(dp,-1);
        dp [0] = 0;

        //从1开始到amount，从小到大进行递归
        for (int i = 1; i <= amount; i++) {
            //在coins数组中开始遍历
            for (int j = 0; j < coins.length; j++){
                //找到比所找金额i小或相等的硬币，并且剩余面额i-coins[j]在之前已经凑到过
                if (coins[j] <= i && dp[i - coins[j]] != -1){
                    //比较是不是比已找过的方案所需硬币数少再替换
                    if (dp[i] == -1 || 1 + dp[i - coins[j]] < dp[i]) {
                        dp[i] = 1 + dp[i - coins[j]];
                    }
                }
            }
        }

        return dp[amount];

    }
}
```

## 单词拆分

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        //动态规划就是递推，将问题划分成子问题
        //此题是把s划分成若干段，使得每段都在wordDict中，判断能否划分成。
        //可以从左往右先去长度为1的子串，如果在 wordDict，则只需判断之后的子串是否可以划分，以此类推。

        //先算出wordDict中子串的最长长度
        int maxLen = 0;
        for(String word : wordDict){
            maxLen = Math.max(maxLen,word.length());
        }

        Set<String> words = new HashSet<>(wordDict);//建立hashset方便查找

        //建立递推数组，储存当长度为n时是否能划分
        int n = s.length();
        boolean dp[] = new boolean[n + 1];
        dp[0] = true;

        for(int i = 1;i <= n; i++){
            for (int j = 0; j < i; j++) {
                //遍历递归数组，将每个字符串划分，枚举划分位置，分成dp[j]和s.substring(j, i)
                // 控制子串长度不超过最大长度剪枝
                if (i - j <= maxLen && dp[j] && words.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

## 最长递增子序列

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        //递推数组dp[i] 表示以 nums[i] 结尾的最长递增子序列的长度（重点）
        int n = nums.length;
        int dp[] = new int[n];

        // 初始化 dp 数组，每个元素初始值为 1，因为每个元素自身可以构成一个长度为 1 的递增子序列
        for (int i = 0; i < n; i++) {
            dp[i] = 1;
        }

        int maxlen = 1;

        for(int i = 1;i < n;i++){
            for(int j = 0;j < i;j++){
                //考虑必须新加一个数时对最长递增序列的影响
                // 如果 nums[i] 大于 nums[j]，则可以将 nums[i] 接在以 nums[j] 结尾的递增子序列后面
                if(nums[i] > nums[j]){
                    dp[i] = Math.max(dp[j] + 1,dp[i]);
                }
            }
            maxlen = Math.max(maxlen,dp[i]);
        }


        return maxlen;
    }
}
```

## 乘积最大子数组

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

```java
class Solution {
    public int maxProduct(int[] nums) {
        int max = Integer.MIN_VALUE, imax = 1, imin = 1;//imax,imin为当前最大最小值
        for(int i=0; i<nums.length; i++){
            if(nums[i] < 0){ //由于存在负数，那么会导致最大的变最小的，最小的变最大的
              int tmp = imax;
              imax = imin;
              imin = tmp;
            }
            imax = Math.max(imax*nums[i], nums[i]);
            imin = Math.min(imin*nums[i], nums[i]);
            
            max = Math.max(max, imax);
        }
        return max;
    }
}
```

分割等和子集

给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

```java
class Solution {
    public boolean canPartition(int[] nums) {
        //0-1背包问题，需要会一维的空间优化方法
        //思路：递推数组，dp[n]中列代表容量，每次加入一个物品，更新一次一维数组
        //目标为和的一半
        int len = nums.length;
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        if ((sum & 1) == 1) {//奇数和不行
            return false;
        }

        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int i = 1; i < len; i++) {
            for (int j = target; nums[i] <= j; j--) {//难点：一定要从后往前

                dp[j] = dp[j] || dp[j - nums[i]];

            }
        }
        return dp[target];
    }
}
```

## 最长有效括号

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 `"(()())"`。

```java
class Solution {
    public int longestValidParentheses(String s) {
        //思路：利用栈，放左括号，当遇到右括号就出栈，算出索引之间的差距，更新最大值
        int maxans = 0;
        Deque<Integer> stack = new LinkedList<Integer>();
        stack.push(-1);//为避免第一个数为右括号不统一，放入-1
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    maxans = Math.max(maxans, i - stack.peek());
                }
            }
        }
        return maxans;
        
    }
}
```
