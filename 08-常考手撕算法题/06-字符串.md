# 字符串

## 字符串相加

给定两个字符串形式的非负整数 `num1` 和`num2` ，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 `BigInteger`）， 也不能直接将输入的字符串转换为整数形式。

![image-20250907193247840](https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250907193247840.png)

```java
class Solution {
    public String addStrings(String num1, String num2) {
        //思路：按位相加计算，利用charAt取出字符串指定索引下的字符，与字符‘0’的差距就是实际的数
        int len1 = num1.length();
        int len2 = num2.length();
        StringBuffer res = new StringBuffer();//可变字符串

        int i = len1 - 1;
        int j = len2 - 1;
        int carry  = 0;//进位
        while (i >= 0 || j >= 0 || carry > 0){
            int n1 = 0, n2 = 0;
            if (i >= 0) n1 = num1.charAt(i) - '0';
            if (j >= 0) n2 = num2.charAt(j) - '0';
            int sum = n1 + n2 + carry;
            int a = sum % 10;
            carry = sum / 10;
            res.append(a);
            i--;
            j--;
        }
        return res.reverse().toString();
    }
}
```

## 字符串相乘

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积，它们的乘积也表示为字符串形式。

**注意：**不能使用任何内置的 BigInteger 库或直接将输入转换为整数。

**示例 1:**

```
输入: num1 = "2", num2 = "3"
输出: "6"
```

**示例 2:**

```
输入: num1 = "123", num2 = "456"
输出: "56088"
```

**提示：**

- `1 <= num1.length, num2.length <= 200`
- `num1` 和 `num2` 只能由数字组成。
- `num1` 和 `num2` 都不包含任何前导零，除了数字0本身。

**思路：**根据手动计算思路一样，用一个数组，先计算按位数乘法的值，然后相加进位。

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250908225258962.png" alt="image-20250908225258962" style="zoom:67%;" />

<img src="https://raw.githubusercontent.com/Yzitong/When-Java-meets-LLM/main/images/image-20250908225304644.png" alt="image-20250908225304644" style="zoom:67%;" />

```java
class Solution {
    public String multiply(String num1, String num2) {
        //首先考虑边界情况，如果有0，则结果一定是0
        if (num1.equals("0") || num2.equals("0")) return "0";
        int m = num1.length();
        int n = num2.length();
        //由于m位数与n位数相乘结果不是m+n-1位就是m+n位
        int ansArr[] = new int[m+n];
        //相乘+累和
        for (int i = m - 1;i >= 0;i--){
             
            int x = num1.charAt(i) - '0';
            for (int j = n -1;j >= 0;j--){
                int y = num2.charAt(j) -'0';
                // 把 x 和 y 相乘的结果存放到 i + j + 1 位（重点）（背）
                ansArr[i + j + 1] += x*y;
            }
        }
        //进位
        for (int k = m + n -1;k > 0;k--) {
            ansArr[k - 1] += ansArr[k]/10;
            ansArr[k] = ansArr[k]%10;
        }
        //确定索引初始位置,数组第一位为0则从1开始，否则从0开始
        int index = ansArr[0] == 0 ? 1:0;
        //把数组转换为字符串
        StringBuffer ans = new StringBuffer();
        while (index < m+n) {
            ans.append(ansArr[index]);
            index ++;
        }
        return ans.toString();
    }
}
```
