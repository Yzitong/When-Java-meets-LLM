# “智道”——通信教育领域智能问答Agent系统

面试官目标验证：
- 你是否真正主导并深入参与了整个项目的链路设计；
- 是否对业务场景有清晰理解；
- 是否掌握关键实现细节（包括架构、数据处理、模型调用、缓存策略、RAG优化等）；
- 遇到过哪些真实的技术挑战，以及你是如何分析和解决的；
- 是否具备独立思考与工程落地能力。

---

### 第一部分：项目整体定位与业务理解

1. **请你用1-2分钟简要复述“智道”项目的背景、核心目标和用户群体。为什么选择通信教育这个垂直领域？北邮的知识图谱是如何构建的？**
   
2. **你说该项目“服务于沙河高教园八大高校，供千余名学生使用”，那么实际的用户行为数据有哪些？比如日均QPS、平均会话轮次、典型问题类型分布？这些数据是否影响了你的系统设计？**

3. **作为主要负责人，你在项目中的具体角色是什么？除了算法和后端开发，有没有参与需求调研、产品定义或部署运维？团队规模多大？其他人负责什么？**

---

### 第二部分：系统架构与链路设计

4. **请画出（或口头描述）整个系统的请求处理链路。从用户输入一个问题开始，到最终返回答案，中间经历了哪些模块？每个模块的技术选型依据是什么？**

5. **你提到使用了 GraphRAG + Neo4j（虽然简历里没写Neo4j但项目亮点提到了图数据库），能否详细说明知识图谱的 schema 设计？比如节点类型、关系类型、属性字段？图谱是如何与原始教材/讲义对齐的？**

6. **GraphRAG 的检索流程是怎么做的？是先做关键词匹配再图遍历，还是直接用 embedding 向量在图上做近邻搜索？有没有结合传统倒排索引？**

7. **你用了 Redis 做缓存，请问缓存的是什么内容？是最终答案、中间检索结果，还是 prompt 模板？缓存 key 的设计逻辑是什么？如何保证缓存一致性（比如知识图谱更新后）？**

8. **整个系统的延迟要求是多少？你提到高德项目响应控制在1.2秒内，“智道”项目的 P95 延迟是多少？有没有做过压测？瓶颈出现在哪个环节（网络、模型推理、图查询、序列化）？**

### 第三部分：模型与算法实现细节

9. **你基于星火大模型 v3.5 构建 Agent，那是否做了微调？如果是，训练数据来源是什么？self-Instruct 扩充的具体方法能否展开？比如 prompt 模板长什么样？如何过滤低质量生成样本？**

10. **你说“研发 LoRA + GPRO 提示词优化模型”，这里的 GPRO 是指什么？是自研方法还是引用某篇论文？LoRA 的 rank、alpha 等超参怎么设置的？微调时用了多少 GPU 显存？训练了多少 epoch？**

11. **损失函数中“核心推导步骤权重1.2-1.5倍”是如何定义“核心步骤”的？是人工标注的吗？标注标准是什么？有没有 inter-annotator agreement（标注者一致性）评估？**

12. **动态 RAG 系统中，“基础问题直接答、推导问题必检索”的判断逻辑是如何实现的？是靠意图分类器（如 prompt 分类）、规则关键词，还是小模型判别？准确率多少？误判案例有哪些？**

13. **Function Call 机制具体怎么集成的？是调用星火 API 的 function calling 能力，还是你自己封装了一套工具调度框架？如果有多个工具（比如查公式、查定理、查例题），如何决定调用顺序或组合？**

### 第四部分：问题排查与优化经验

14. **在上线过程中，有没有遇到模型“幻觉”严重的问题？比如编造不存在的通信协议或公式？你们是如何缓解的？有没有引入拒答机制或置信度阈值？**

15. **有没有出现过 GraphRAG 检索不到相关内容但用户问题其实可答的情况？这时候 fallback 策略是什么？是走通用 LLM 回答，还是返回“知识库未覆盖”？**

16. **Redis 缓存击穿或雪崩有没有发生过？比如某个热门问题（如“香农公式是什么”）突然被大量并发请求打爆？你们的防护措施是什么？布隆过滤器？互斥锁？还是本地缓存+多级缓存？**

17. **MySQL 和 Neo4j 之间的数据同步是如何保证的？如果图谱更新了新知识点，但 MySQL 中的历史对话记录仍引用旧版本，会不会导致答案不一致？如何做版本管理或快照？**

### 第五部分：成果验证与反思

18. **你说“问答匹配率提升22%”、“回复准确率提升15%”，这些指标是如何定义和测量的？是人工评估还是自动指标（如 BLEU、ROUGE、Exact Match）？评估集有多少条样本？由谁标注？**

19. **有没有 A/B 测试？比如对比纯 RAG vs GraphRAG vs 微调模型？各项指标具体差异是多少？延迟、准确率、用户满意度分别如何变化？**

20. **如果现在让你重新做这个项目，你会在架构或算法上做哪些改进？比如换用更小的本地模型（Qwen-Max → Qwen-Plus）、引入多跳推理、或者用向量数据库替代部分图查询？**
